# The Shell Part I — Thai Translation Mod

# 📥 ดาวน์โหลดม็อดภาษาไทย (Download)
> 🚀 **[คลิกที่นี่เพื่อดาวน์โหลดม็อดเวอร์ชันล่าสุด (GitHub Releases)](https://github.com/sakiskullia/the-shell-part-i-thai-mod/releases/latest)**
ม็อดภาษาไทยแบบไม่เป็นทางการสำหรับ **The Shell Part I / Kara no Shoujo Part I**

โครงการนี้จัดทำขึ้นเพื่อให้ผู้เล่นชาวไทยสามารถอ่านเนื้อเรื่องได้สะดวกขึ้น โดยใช้ข้อความภาษาญี่ปุ่นเป็นแหล่งอ้างอิงหลัก ส่วนช่องภาษาอังกฤษของเกมถูกใช้สำหรับแสดงคำแปลภาษาไทย

> สถานะคำแปล: **564/564 ไฟล์**

---

## คุณสมบัติ

- แปลเนื้อเรื่องหลักครบ 564/564 ไฟล์
- ตรวจน้ำเสียงและความหมายโดยอิงข้อความภาษาญี่ปุ่นเป็นหลัก
- ปรับสรรพนาม คำลงท้าย และระดับภาษาให้เหมาะกับบุคลิก ความสัมพันธ์ และเพศของตัวละคร
- ปรับสำเนียงและรูปแบบการพูดของตัวละครบางคนตามต้นฉบับ
- ใช้ฟอนต์ **Ekkamai Vibe** สำหรับการแสดงผลภาษาไทย
- ปรับขนาดตัวอักษร ระยะบรรทัด และการตัดบรรทัดให้เหมาะกับระบบของเกม
- แก้ปัญหาสระและวรรณยุกต์ไทยซ้อนกันหรือแสดงผลไม่ครบ
- แปลภาพข้อความและองค์ประกอบภายในเกม เช่น
  - ฉากข้อความพื้นขาวและพื้นดำ
  - การ์ดแบ่งบท 27 ภาพ
  - การ์ดวันที่และข้อมูลดวงจันทร์ 52 ภาพ
  - หน้าสมุดบันทึก รายชื่อตัวละคร สิ่งของ และหลักฐาน
  - แผนที่และชื่อสถานที่
- มีตัวติดตั้งแบบ GUI ไม่จำเป็นต้องเปิด Command Prompt
- ตัวติดตั้งสำรองไฟล์เดิมก่อนติดตั้งม็อด
- ไม่ลบหรือแก้ไขโฟลเดอร์เซฟเกม

---

## ความต้องการของระบบ

- Windows 10 หรือ Windows 11 รุ่น 64 บิต
- เกม **The Shell Part I** ฉบับถูกลิขสิทธิ์
- แนะนำให้ตั้งภาษาภายในเกมเป็น **English**
- พื้นที่ว่างเพียงพอสำหรับไฟล์ม็อดและไฟล์สำรอง

---
